Project Site Plan

Matrix Tech: Graphic Design & Tech Solutions

1. Site Name & Domain

Selected Site Name: Matrix Tech: Graphic Design & Tech Solutions

Optional Domain Availability: matrixtechssd.com / matrixtech.org

Reason for Selection: This name directly identifies the brand and establishes immediate recognition for existing clients. It clearly communicates the dual nature of our agency: delivering creative graphic design and branding assets alongside robust technical solutions (such as hotspot voucher systems, network installations, and Starlink hardware setup) across South Sudan.

2. Site Purpose

The primary purpose of the Matrix Tech website is to serve as a comprehensive digital portfolio and service inquiry hub for businesses and organizations in South Sudan. Specifically, the site will:

  • Showcase a gallery of professional graphic design work, corporate branding kits, and apparel printing layouts.
  • Detail our technical service offerings, including local network administration, MikroTik hotspot configuration, and Starlink satellite internet installations.
  • Provide a seamless, dynamic interactive service catalog where prospective clients can filter services by category and submit consultation requests.

3. Target Audience & Scenarios

Target Audience

Our target audience includes small-to-medium business owners, non-profit organizations, and corporate clients across South Sudan who require reliable brand identity design and stable local office network infrastructure.

Visitor Scenarios

  1. "How can I request a custom logo and corporate branding package for my business in Juba?"

    Answered via: The interactive Services Catalog page and dedicated "Request a Quote" call-to-action buttons.

  2. "Do you supply and configure Starlink hardware or MikroTik hotspot vouchers for remote field offices, and what is the turnaround time?"

    Answered via: The Tech Solutions detail cards on the Home and Discover pages, which outline hardware specifications and deployment timelines.

  3. "Where can I see examples of past logo designs and client branding projects before scheduling a consultation?"

    Answered via: The visual Portfolio/Discover grid featuring real project samples and verified client branding assets.

4. Color Scheme

The color palette is derived directly from the Matrix Technologies brand identity—balancing corporate authority with modern technical energy.

Color Name Hex Code Visual Sample Application on Website
Deep Navy Blue #0F172A
Used for the main header background, primary page headings (h1, h2), footer background, and primary structural borders.
Cyan Tech Blue #0284C7
Used for interactive links, table header backgrounds, border highlights, and secondary call-to-action buttons.
Matrix Crimson #E11D48
Used sparingly for accent indicators, important badges, button hover states, and key feature callout tags.
Slate Dark Text #1E293B
Used for all body paragraphs, lists, and table text to ensure WCAG AA high-contrast readability against light backgrounds.
Off-White Canvas #F8FAFC
Used as the primary page background and card container spacing filler.
